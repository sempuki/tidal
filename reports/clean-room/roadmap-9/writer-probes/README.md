Commit read: `a15a877d`. The grids ran with `tools/probe_grid.py --errors` on
the baseline compilers (Clang 18, Clang 22 in its container and on the host,
GCC 14, GCC 16 in its container and on the host, EDG 7.0, and EDG 7.0 ILP32).
The `.cpp` probes ran on the host `g++` (GCC 16) and `clang++` (Clang 22)
only, because they need a run or a link; `host-probes.out` holds their output.

| `r10-4-return-local-unset.json`, `.out` | R10-4: a `constexpr` function returns a local class object whose member `b` has no value, and the caller reads only `a` | GCC 14 and 16 accept every form. Clang and EDG reject the return of a named local, a parenthesized local, and a local through a conditional, in a `static_assert`, through a local copy, and as a `constexpr` variable. A prvalue return (`return S();`) is accepted everywhere when only `a` is read; as a `constexpr` variable of type `S` it splits the same way (CE-21). With every part set, every compiler accepts. |

| `i3-13-list-worst-element.json`, `.out` | I3-13: which element a list sequence holds when several elements have user-defined conversions | Overloads on `const int (&)[2]` and `const long (&)[2]`, and on `std::initializer_list<int>` and `<long>`. `P` converts to `int`, `Q` to `long`. Clang and EDG choose by the first element of the list: `{P, Q}` selects the `int` form and `{Q, P}` the `long` form; `{P, P}`, `{P, 0}`, and `{P, 0L}` select `int`.
