# Writer probes, roadmap round 10

Commit read: `ebc109b9`. The grids ran with `tools/probe_grid.py --errors` on
the baseline compilers (Clang 18, Clang 22 in its container and on the host,
GCC 14, GCC 16 in its container and on the host, EDG 7.0, and EDG 7.0 ILP32).
The two sanitizer grids ran on the GCC and Clang compilers only, because EDG
takes no sanitizer flag. `q-0421-library-allocator.cpp` ran on the host `g++`
(GCC 16) and `clang++` (Clang 22) only, because it includes `<memory>`, which
EDG does not have; `q-0421-library-allocator.out` holds the result.

| `w20-2-union-array-member.json`, `.out` | W20-2: `std::construct_at` on an element of an array member of a union, in constant evaluation | Clang 18 and 22 and GCC 14 reject every form, for `int` and class elements, with no active member and with another member active. Clang's note says that the construction of a subobject of a member of a union with no active member (or with another active member) is not allowed. GCC 16 and EDG accept every form: element 0, element 1 alone, both, a read of element 1 through a pointer to element 0, and through the pointer that `construct_at` returns. An assignment to an `int` element (UNI-13) is accepted everywhere. An assignment to a class element with no trivial default constructor is rejected by GCC and Clang and accepted by EDG. A read of an element that nothing built is rejected by GCC and Clang where no member is active; EDG accepts it, and GCC 16 accepts it with another member active. |

| `w20-4-tag-address-plain.json`, `-ubsan.json`, `-null.json`, `.out` | W20-4: `!=` on the addresses of two variables in `static_assert` | With the matrix flags alone, every compiler accepts every row. | `g153-cond-private-base.json`, `.out` | G153: COND-16 step 1 with a private or ambiguous base | Every compiler: in a friend of `Hidden`, where the private base is accessible, `b ? hidden : root` is a `Root` lvalue. No probe tells the two readings of G153 apart, because both reject. |
| `g154-private-copy-selected.json`, `.out` | G154: the access of the constructor that a copy selects | Every compiler rejects a copy-initialization, a by-value argument, a return of a parameter, and a return of a local, each with a private copy constructor, and the xvalue and local-return forms with a private move constructor. | `g156-assign-before-construction-types.json`, `.out` | G156: LSUP-11 for other element types | The split of Q-0421 holds for every element type in the grid: `double`, a pointer, an enumeration, `char`, a whole element of a simple class, and a class with a user-written assignment operator. | `g157-virtual-instantiation-events.json`, `.out` | G157: which uses instantiate a virtual function that no use names | Every compiler instantiates the virtual function (reject) for an object at namespace scope, a local object in a function never called, a `new` expression, a temporary, and an object of a derived class. A call of the virtual function itself through a pointer: GCC and Clang reject, EDG accepts. An explicit instantiation declaration before an object: GCC and Clang accept, EDG rejects. |

| `q-0422-binding-category.json`, `.out` | Q-0422: EDG's type for `return (a)` of a structured binding | EDG 7.0 gives `int&&` for a binding of a local object and also for a binding declared `auto&` to a local object. Clang and GCC give `int&` for both. `return a;` gives `int` everywhere. |
