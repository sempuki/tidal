# Writer probes, roadmap round 15

Commit read: `7a849708`. The grids ran with `tools/probe_grid.py --errors`
on the baseline compilers (Clang 18, Clang 22 in its container and on
the host, GCC 14, GCC 16 in its container and on the host, EDG 7.0, and
EDG 7.0 ILP32), each run under the run lock, in a worktree of the
repository. `writer-scratch/make_grids.py` writes the JSON files. Each
`.out` file holds the table and the first error of each compiler that
rejects. The paths of the host compilers in the `.out` files start at
the worktree.

The grids compile only, with `-c`. A probe that needs a value puts it in
a `static_assert`, so EDG takes part. The `x26-warnings` grid passes
`-Werror` with `-Wunused-value`, so a reject there is a warning, and EDG
skips the grid, as it skips the warning-flag tests of the matrix. The
EDG container has no standard library headers, so EDG rejects every row
of `x26-library` at its first `#include`, controls included.

`writer-scratch/run_probes.py` builds and runs the X26 probes on the six
compilers that build (Clang 18, Clang 22 in its container and on the
host, GCC 14, GCC 16 in its container and on the host), and lists the
warning lines of `w1.cpp`, `t1.cpp`, `f1.cpp`, and `m1.cpp`. Its output is
`run-probes.out`.
