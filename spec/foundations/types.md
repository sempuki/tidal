# Fundamental types

A fundamental type is built into the language. This page lists the
fundamental types and the type specifiers that name them: `void`, the
type of `nullptr`, `bool`, the character types, the signed and unsigned
integer types, and the floating-point types. It gives the integer and
floating-point conversion ranks, and the size, alignment, and range of
each type on the matrix targets.

Depends on: translation, execution, and behavior classes; declarators and
cv-qualifiers.
