# 0054. Phase 7: close the record, test by whole programs, and review every page

Date: 2026-11-03
Status: Provisional. Extends 0033, 0039, 0050, and 0051. The maintainer can
reorder or drop any item.

## Context

Phases 1 to 6 are done. Five clean-room views ranked what comes next
(`reports/clean-room/roadmap-4/`): a programmer, an implementer, an
editor, a clean-room writer, and a language designer. They agree on
these points:

- No topic needs a new page. The cost sits in open questions, review
  coverage, and records that drift.
- Open questions rose from 290 to 310 in phase 6. The settling rule of
  decision 0051 needs every newest family to agree. It settled 1 of the
  82 questions in clusters 2 to 6, because those clusters are splits by
  construction. About 49 open questions have a gap review that supports
  the provisional answer with no doubt, and they stay open only because
  one family differs. 217 open questions have no gap review.
- Decision 0051 asked that every Write program become a run test. None
  did. A run of the 67 programs in the interpreter found two false
  rejects that no test catches.
- Records drift again. `tests/RESULTS.md` covers 5609 of 6032 tests, no
  committed similarity report covers `questions/`, the roadmap marks
  only some phase 6 rows, and the front-end row of
  `documentation/exercises.md` is at round 10.
- Eleven pages (the exceptions chapter, names, objects, storage,
  language-support types, translation, the one-definition rule, types,
  and keywords) have never had a gap review. Ten pages, among them the
  overloading chapter and storage, have never had a Predict batch.
- An interpreter that matches the matrix needs a choice for every
  `impl-defined` rule. Some rules give none (CONV-7, CONV-11, CAST-12),
  and the class layout of the matrix sits only in Evidence. STG-25 and
  the CLS-34 Evidence give different conditions for reuse of end
  padding.
- 13 `undefined` rules have no test that a tool checks at run time.
- Propose reports cite rules that phase 6 withdrew. Five declarations
  pages have had no Propose exercise.

## Decision

Phase 7 has these items, in this order. Items in one row can run in
parallel.

| Item | Work | Source views |
|---|---|---|
| R1 | Close the phase 6 record: a full matrix run that rewrites `tests/RESULTS.md`; `questions/` in every similarity run and one whole-repository report; the state of every phase 6 roadmap row; the front-end row of `exercises.md` from `conformance.tsv`; the cluster 2 review's reading on every question it read; Q-0312 provisional | writer, editor, programmer |
| WP | The Write programs become run tests under `tests/programs/`, cited by the rules their reports name. They do not count toward the decision 0044 proxy | programmer, implementer, editor |
| SR | A second settling rule (below), applied to the reviewed questions, and one decision packet for the maintainer | editor, writer |
| TP | A matrix choice for every `impl-defined` rule, the matrix layout as a table that a rule links, and STG-25 made consistent with it | implementer |
| UW | A run witness for each `undefined` rule: a `run-fail` test, or a `tidal-interpreter: run-fail` line, or a note that no tool stops it | writer, implementer |
| GR | Source-reader gap reviews of the eleven pages that never had one, then of the open questions with no review, in clusters | writer, editor |
| PR | Predict batches for the pages with no batch, first the overloading pages and storage | editor, writer, implementer, programmer |
| FE | Front-end rounds from 15: class layout from TP, allocation functions by name, virtual bases, the false rejects, and the Write programs | implementer, programmer |
| X | A refresh check for Propose reports, then Propose round 4 (X13 to X16) for the five unreached declarations pages | designer |

These choices hold until the maintainer decides otherwise:

- **Settling by review.** The rule of decision 0051 stays. A question
  also settles when its gap review supports the provisional answer with
  no doubt, and a principle on the page gives the same answer. The
  question records the differing family's result, and the test keeps
  its override. A review that reads against the answer, or reads with
  doubt, keeps the question open. A contributor can reopen a settled
  question.
- **The decision packet.** The items that wait on the maintainer move
  into one file, `documentation/decisions/pending.md`, with one row per
  item. Each row gives the options, the answer Tidal keeps until the
  maintainer decides, and the questions the decision closes.
- **Program tests.** A test under `tests/programs/` is evidence from
  use. It cites the rules its report names, and a rule that only such a
  test cites still needs a test of its own.
- The choices of decision 0051 on class properties and library names
  stay.

Scope stays as decision 0051 says. Port suites, Diagnose batches beyond
D-classes, guides, and the index of later-version acceptances wait for
a later phase.

## Consequences

- `documentation/roadmap.md` gains a phase 7 table, and
  `documentation/status.md` points its next steps at it.
- Each phase 7 commit that settles questions states the open count
  before and after. The phase aims to end with fewer open questions
  than the 310 at its start.
- Each commit that acts on a review records the review's reading on
  every question the review read.
- The last step of the phase runs the full matrix with `--report`, a
  whole-repository similarity report, and `tools/status_table.py`, and
  marks the roadmap rows.
