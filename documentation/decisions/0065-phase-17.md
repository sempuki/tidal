The 15 `open` rows of the exercise ledger now name item F7
(`reports/clean-room/ledger.md`). The front-end rows G166 to G179 stay
`open` and name item GR.

These choices hold until the maintainer decides otherwise:

- **Grammar text comes before parser code.** A parser function in
  `frontend/next/` lands only for a production that a Syntax segment
  gives.
- **Ownership moves test by test.** At the end of build step 3, each
  test that the new front end passes and that needs only step 3 pages
  can join the takeover list. A listed test that the new front end then
  fails is a worse status.
- The choices of decisions 0051, 0054, 0055, 0056, 0057, 0058, 0059,
  0061, 0062, 0063, and 0064 stay.

A narrow second review of the doubt-held questions, principle sentences
and a use batch for the questions that wait for one, Implement I8 on
instantiation, Port suite P5, guides, refresh notes for the done
designs, an index of what a test of validity can see, reject tests that
pass on a grammar error, and first tries in the completion count wait
for a later phase. Later versions stay out of scope until the
maintainer decides `pending.md` row 7.
