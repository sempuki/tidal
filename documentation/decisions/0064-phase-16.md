These choices hold until the maintainer decides otherwise:

- **The old front end stays the front end of record** until the
  rewrite owns a test. Its rounds keep "0 worse". No round fixes a
  marked test in the old code. A round that changes a file the rewrite
  moved makes the same change in the new crate.
- **The gate's count becomes a measure.** With the rewrite started, a
  count above 50 stops no item. Each round report gives the count with
  the marks the round started with and names a cause for each test.
- **A review summary lands with its question records** in one commit.
- **Every commit message gives the result of both checks**
  (`check_specification.py` and `question_index.py --check`).
- **A "left open" line in a commit message becomes a ledger row** in
  the same commit.
- The choices of decisions 0051, 0054, 0055, 0056, 0057, 0058, 0059,
  0061, 0062, and 0063 stay, except that the gate of 0062 and 0063 is
  now a measure.
