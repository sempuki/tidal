# Q-0116: Should a designer persona that knows WG21 papers also run, as a source reader?

**Status:** provisional
**Affects:** decision 0037, `docs/exercises.md`

## Context

Decision 0037 adds a language-designer persona that takes all of its
C++ knowledge from Tidal. The maintainer first described a reader who
has read many WG21 papers. AGENTS.md makes such a reader a source
reader.

## Evidence

AGENTS.md rules 1 to 4. Decision 0029, which keeps clean-room readers to
Tidal's own files.

## Options

1. Run only the clean-room designer. Every gap it meets is a finding.
2. Also run a source-reader designer. It can say which kinds of design
   questions proposals usually raise that Tidal cannot answer. Its
   report is a summary under rules 2 to 4, checked for similarity, with
   no code, no wording, and no paper names.

## Provisional answer

Option 1. The clean-room designer finds gaps without a protected input.
Option 2 can follow if its roadmap misses whole areas.
